    How ContractGuard works

    Upload a text-based PDF. The app extracts text, segments clause candidates, matches relevant drafting checklists, and generates findings with suggested revisions.

    • Use a non-sensitive sample contract for your demo.
    • Every finding is a prompt for human review, not a verified legal conclusion.
    • Scanned PDFs and OCR are not supported in this MVP.
    • Add an OpenAI API key only if you want optional AI-generated summaries.
